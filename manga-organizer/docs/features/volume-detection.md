# 巻番号推定ロジック仕様書

## 概要

マンガアーカイブから巻番号を推定するロジックの仕様を定義する。

## 基本原則

**巻番号推定ロジックは、画像を直接含むディレクトリの名前に含まれる数字の組を配列で抽出し、その配列の最後方の数字を巻番号とする**

## 処理フロー

### 1. アーカイブ処理

1. アーカイブを一時ディレクトリに展開
2. ネストされたアーカイブがあれば再帰的に展開
3. 画像を直接含むディレクトリをすべて検出

### 2. 巻番号推定

各画像ディレクトリに対して以下の手順で巻番号を推定：

#### 2.1 優先順位

1. **画像ディレクトリ名からの推定**（最優先）

   - 画像を直接含むディレクトリの名前から巻番号を推定
   - 例：`001/` → 1 巻、`vol_05/` → 5 巻

2. **単一ボリュームアーカイブの場合のみアーカイブ名から推定**

   - 画像ディレクトリが 1 つだけの場合、アーカイブ名も参考にする
   - 例：`manga_vol_03.zip`（単一ディレクトリ）→ 3 巻

3. **フォールバック**
   - 巻番号が推定できない場合は、処理順序のインデックスを使用

#### 2.2 数字抽出ロジック

1. ディレクトリ名から正規表現で数字の組をすべて抽出
2. 配列の最後の数字を巻番号として採用
3. 例：
   - `chapter_01_page_50` → [1, 50] → 50 巻
   - `vol_003` → [3] → 3 巻
   - `001` → [1] → 1 巻

## 具体例

### ケース 1：複数巻を含むアーカイブ

```
DLRAW.TO_3Gatsu Lion vol 01-17.rar
├── 3-gatsu no Lion/
│   ├── 001/           # → 1巻
│   │   ├── 001.jpg
│   │   ├── 002.jpg
│   │   └── ...
│   ├── 002/           # → 2巻
│   │   ├── 001.jpg
│   │   └── ...
│   └── 017/           # → 17巻
│       └── ...
```

### ケース 2：単一巻アーカイブ

```
manga_vol_05.zip
└── images/            # → 5巻（アーカイブ名から推定）
    ├── page_001.jpg
    └── ...
```

### ケース 3：ネストされたアーカイブ

```
collection.rar
├── vol_01.zip        # 展開後、内部ディレクトリから推定
├── vol_02.zip
└── vol_03.zip
```

## 注意事項

- 一時ディレクトリ（`manga_*`, `_extracted_*`, `temp*`）は巻番号推定の対象外
- 特定のボリュームパターン（`vol`, `v`, `第X巻`, `#`など）は優先的に認識
- 複数の数字が含まれる場合は最後の数字を採用（ページ番号より巻番号が後に来ることが多いため）

## 実装上の考慮事項

- `detect_volume_from_archive()`メソッドは単一巻アーカイブの判定にのみ使用
- 複数巻を含むアーカイブでは、各画像ディレクトリから個別に巻番号を推定
- 巻番号の推定に失敗した場合のフォールバック処理を必ず実装
