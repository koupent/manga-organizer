# 変更履歴

## [3.6.3] - 2024-12-XX（開発中）

### 追加

- タイトル・作者入力機能の大幅改善
  - リアルタイムサジェスチョン機能
  - DB + API 統合検索
  - 日本語作者名の優先取得（AniList API 使用）
- ドキュメントの全面再構成

### 変更

- タイトル入力時のフォーカス管理改善
- 作者欄の API 検索を遅延実行に変更（フォーカス時のみ）
- MyAnimeList API を削除し、AniList API に統一

### 修正

- タイトルクリア時に作者欄が残る問題を修正
- 3 文字入力時にフォーカスが奪われる問題を修正
- キーボード削除時の作者欄クリア不具合を修正

## [3.6.2] - 2024-11-XX

### 追加

- 巻番号検出ロジックの改善
- 複数巻を含むアーカイブからの巻番号の正確な検出

### 変更

- 画像ディレクトリ名を優先的に使用するように変更

### 修正

- 巻番号推定の精度向上

## [3.6.1] - 2024-11-XX

### 追加

- rarfile モジュールのサポート

### 変更

- ビルドスクリプトの最適化

### 修正

- rar ファイルの処理エラーを修正

## [3.6.0] - 2024-10-XX

### 追加

- タイトル・作者のデータベース保存機能
- API 連携による作品情報取得

### 変更

- パフォーマンスの最適化

## 開発ガイドライン

### バージョニング

セマンティックバージョニング（SemVer）を採用

- メジャー: 破壊的変更
- マイナー: 機能追加（後方互換性あり）
- パッチ: バグ修正

### リリースプロセス

1. 機能開発・バグ修正
2. テスト実施
3. ドキュメント更新
4. バージョンタグ付与
5. リリースノート作成
