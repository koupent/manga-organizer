# Manga Organizer

日本語漫画アーカイブを自動整理・再パッケージ化する Windows 向け GUI アプリケーション

[![Release](https://img.shields.io/github/v/release/koupent/manga-organizer)](https://github.com/koupent/manga-organizer/releases)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## 🎯 主な機能

### 📚 アーカイブ管理

- **多形式対応**: ZIP, RAR, 7z, CBZ, CBR, CB7, EPUB
- **ネスト処理**: アーカイブ内のアーカイブも自動展開
- **巻番号自動検出**: 第 X 巻、vol.X、vX など多様なパターンに対応
- **画像リネーム**: 001.jpg, 002.jpg...の連番に自動変換

### 🗂️ データベース機能

- 作品・作者情報の永続管理
- JSON 形式でのエクスポート/インポート
- 重複作品の自動認識

### 🌐 API 連携

- AniList/MyAnimeList 連携で作者名自動取得
- 日本語作者名優先
- API キャッシュによる高速化

### 🖥️ ユーザーインターフェース

- ドラッグ&ドロップ対応
- リアルタイム処理ログ
- 自然順ソート（1→2→10 の正しい順序）
- 完全日本語 UI

### ✂️ ページの余白カット

「ファイル編集」の「ページを分割」と「ページを結合」の間にある「余白カット」で、全ページに共通する白い縁を調べ、切り取り量を提案します。左右・上下の割合を調整し、チェックしたページへ一律に適用できます。画像をクリックすると範囲を拡大確認できます。一覧の並び方・表示サイズ・削除ページの表示設定は各モードで共通です。

分割・結合などを編集中の場合は、先に「変更を反映」で保存してください。単ページへ分割 → 余白カット → 必要なページを結合、の順で操作すると見開き中央の白い帯を減らせます。元画像はアーカイブ内に保持します。

「切り取り前に戻す」で、チェックしたページの直前の余白カットを復元できます。分割・結合・サムネイル調整・ページ順は維持し、保存した画像を再圧縮せず戻します。繰り返しカットした場合は1回ずつ戻せます。旧版は直前の画像が保存されている切り取りのみ復元でき、余白とサムネイルの切り取りを区別できないため、旧版のサムネイル切り取りも復元対象になる場合があります。

## 🔧 前提条件

### RAR 形式のアーカイブを扱う場合

MangaOrganizer で RAR 形式（.rar, .cbr）のファイルを処理するには、7-Zip のインストールが必要です。

#### 7-Zip のインストール方法（推奨）

1. **公式サイトからダウンロード**

   - [7-Zip 公式サイト](https://www.7-zip.org/download.html)にアクセス
   - Windows 64-bit 版（例：7z2408-x64.exe）をダウンロード

2. **インストール**

   - ダウンロードしたインストーラーを実行
   - デフォルト設定（C:\Program Files\7-Zip\）でインストール
   - 管理者権限が必要な場合があります

3. **確認**
   - インストール後、MangaOrganizer が自動的に 7-Zip を検出します
   - RAR 形式のファイルが処理できるようになります

#### 注意事項

- **ZIP, 7z, CBZ 形式**: これらの形式は 7-Zip なしで処理可能です
- **WinRAR**: 代替として[WinRAR](https://www.win-rar.com/)も使用可能ですが、有料ソフトです
- **v3.8.0 以降の変更**: セキュリティ向上のため、7za.exe のバンドルを廃止しました（Breaking Change）

## 📥 インストール

Windows 10 / 11（64 bit）向けです。インストーラはこのリポジトリの Releases に置いてあり、ログインせずにダウンロードできます。

1. [最新の Release](https://github.com/koupent/manga-organizer/releases/latest) の Assets から `MangaOrganizer-vX.X.X-setup.exe` をダウンロード
2. ダウンロードしたファイルを実行
   - 「Windows によって PC が保護されました」と出たら「**詳細情報**」→「**実行**」を押します（コード署名をしていないために出る警告です）
   - 管理者権限は要りません（自分のユーザーにだけ入ります）
   - 画面の部品（WebView2）が無い古い Windows では、途中で自動的に取り込みます（インターネット接続が必要）
3. スタートメニューの「Manga Organizer」から起動

**更新**: v4.1.2 からは、起動したときに新しい版があればアプリの上部に知らせが出ます。「更新する」を押すと、ダウンロードしてアプリがいったん閉じ、入れ替わってから起ち上がり直します。設定と辞書は残ります。v4.1.1 以前を使っている場合は、一度だけ v4.1.2 以降のインストーラを手で実行してください（v4.1.1 は更新を以前の配布用リポジトリに確かめに行くため、新しい版に気づきません）。

**アンインストール**: Windows の「設定」→「アプリ」→「インストールされているアプリ」から「Manga Organizer」を削除します。

### データの置き場所

`%APPDATA%\dev.koupent.manga-organizer\` に作品の辞書などの設定と、裏で動く処理の記録 `sidecar.log` を置きます。アンインストールしても残るので、要らなければ手で消してください。

## 🚀 使い方

起動すると「ディレクトリ整理」と「ファイル編集」の 2 つのタブがあります。ディレクトリ整理の基本の流れ:

1. **作品情報**: 左上に作品名を入れると、著者の候補が出ます（辞書・AniList）
2. **投入したもの**: 整理したいフォルダやアーカイブをウィンドウにドラッグ&ドロップするか、「選んで追加」から辿って入れます。どのドライブでも扱えます
3. **出来上がる本**: 右に、投入元をまたいでできあがる本の名前と巻数が順番に並びます。長い元パスは中央を省略し、マウスを重ねると全文を確認できます。巻数が違うときは「第NNN巻」を押して直せます。見出し付きの表で、変換後の名前のすぐ右に画像枚数を表示します。見出しの右端をドラッグすると各列の幅を変更できます。選択ルールの「同じ巻で画像枚数最多」で最多の候補を選び直し、「下限以上のみ」で少ない候補をまとめて外せます。下限は隣の設定リンクから変更できます。設定の「画像枚数の下限」未満の本は自動でチェックを外します（0は除外なし）。手動で選び直すこともできます
4. **出力先**: 左下で保存先を選びます。参照ダイアログ上部にパスを入力して移動できます。右上の設定でデフォルトの出力先を保存すると、次回起動時もその場所を使います（未設定なら最初に入れたものの場所が入ります）
5. 「**この内容で整理する**」を押すと、出力先に整理済みの ZIP ができます

変換後の名前の鉛筆ボタンで、巻番号以外も含めて出力ファイル名全体を変更できます。「自動の名前に戻す」で通常の命名に戻せます。

### ファイル編集

出来上がる本の編集ボタン、または「ファイル編集」から ZIP を開くと、共通のページ一覧が出ます。

- ページの「⋯」または右クリックから「サムネイルにする」「サムネイルの画像調整」を選べます。サムネイルは先頭に移り、青枠で表示されます。
- 「モード選択」は「ページを分割」「ページを結合」の2つです。どちらでもサムネイルやページ順を編集できます。候補の送りボタンは、末尾から先頭・先頭から末尾へ循環します。
- ページの並びと結合プレビューは両モードで共通です。手動で結合した画像も、結合の件数と候補送りに含みます。結合候補は端の色と正規化相関を比べ、高さの約6%までの上下ずれや明るさ・コントラストの差を考慮します。候補の確認を補助する判定なので、自動で結合は確定しません。
- ページの「⋮」または右クリックから「ページを削除（復元可能）」を選ぶと、通常の一覧と保存後の本文から外れます。「削除したページも表示」をオンにし、同じメニューから復元できます。復元用画像をZIP内に保持するため、保存して開き直した後も復元でき、ZIP容量を減らす操作ではありません。
- 分割側の「分割対象」で「元から横長の画像」「結合・復元した画像」「両方」を選べます。候補の送りと「すべて分割」は選んだ種類に適用されます。既存の記録では結合と復元を区別していないため、同じ種類として扱います。結合側は結合の選択と未保存の結合の取り消しを行い、保存済みの画像を分ける操作は分割側に集めています。
- 取っ手をドラッグするとページ順を変更できます。Ctrl／Shift＋ページ名のクリックで複数選択し、まとめて移動できます。虫眼鏡で原寸表示、Ctrl＋Zで直前の編集を取り消せます。
- 「右から左に表示」は一覧の表示方向だけを変えます。保存するページ順は変わりません。
- 編集したら右上の「変更を反映」でまとめて保存します。変更がないときも「確認済みにする」で確認の記録を残せます。画像やページ名、ファイルの更新日時は保持します。確認・保存後はボタンが無効になり、さらに編集すると再び保存できます。

### 出力形式

```
[作者名] 作品名/
├── [作者名] 作品名 第001巻.zip
├── [作者名] 作品名 第002巻.zip
└── [作者名] 作品名 第003巻.zip
```

各 ZIP ファイル内:

```
001.jpg  # ページ順に連番
002.jpg
003.jpg
...
```

## 🔧 高度な機能

### データベース管理

「DB 編集」ボタンから:

- 登録済み作品の編集・削除
- 新規作品の手動追加
- JSON エクスポート/インポート

### 巻番号検出ロジック

優先順位:

1. **画像ディレクトリ名**: `001/`、`chapter_05/`など
2. **アーカイブ名**: 単一ボリュームの場合のみ
3. **フォールバック**: 処理順序のインデックス

特殊判定:

- 番外編、外伝、短編などの認識
- 一時ディレクトリ名は無視

## ❓ トラブルシューティング

### よくある質問

**Q: RAR ファイルが開けない**

- A: v3.8.0 以降は 7-Zip のシステムインストールが必要です。上記の[前提条件](#前提条件)セクションを参照してください

**Q: 巻番号が正しく検出されない**

- A: ファイル名に「第 X 巻」「vol.X」などを含めてください

**Q: 「Windows によって PC が保護されました」と出る／ウイルス対策ソフトが警告を出す**

- A: コード署名をしていないため、初めて実行するときに出ます。「詳細情報」→「実行」で進めてください。
  - ウイルス対策ソフトが止める場合は、インストール先（`%LOCALAPPDATA%\Manga Organizer`）を除外設定に追加してください

**Q: 起動したが「未接続」のまま、またはエラーが出る**

- A: 裏で動く処理が起動できていません。表示されたメッセージと `%APPDATA%\dev.koupent.manga-organizer\sidecar.log` を添えて Issue で知らせてください

**Q: API 連携が動作しない**

- A: インターネット接続を確認してください

### エラーが発生した場合

1. 画面のエラーメッセージと `sidecar.log`（[データの置き場所](#データの置き場所)）を確認
2. [Issues](https://github.com/koupent/manga-organizer/issues)で既知の問題を検索
3. 新しい Issue を作成して報告
